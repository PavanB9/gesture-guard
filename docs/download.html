Download (.dmg)
Camera permission is requested on first launch. Gesture Guard then appears in System Settings → Privacy & Security → Camera.

First launch: the builds are unsigned

Gesture Guard ships without a paid code-signing certificate, so both systems will warn you the first time. This is a cost thing, not a safety thing — the source is public and you can build it yourself.

Windows — SmartScreen shows a blue box. Choose More info → Run anyway.

macOS — Gatekeeper quarantines the app and may claim it is “damaged”. It isn't. Clear the quarantine flag once: 

xattr -cr "/Applications/Gesture Guard.app"

What you need

A webcam, and roughly 400 MB of disk space — the installer bundles the Python detection engine and the MediaPipe models so the app is fully offline after install.

Prefer to build from source? The full setup is in the README.
